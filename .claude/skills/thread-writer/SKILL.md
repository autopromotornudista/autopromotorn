# Thread Writer

## Three Rules

1. **Opener decides everything** — Post 1 must hook AND promise payoff. It's the reshareable anchor.
2. **One idea per thread, one per post** — Each post advances exactly one beat
3. **Every post earns the next** — Cut anything that doesn't pull the reader forward

## Thread Structure

```
Post 1: Hook + promise ("Hice X y descubrí algo que nadie te cuenta sobre Y — hilo 🧵")
Post 2: Context / why this matters
Posts 3-N: One insight per post, front-loaded point first
Post N-1: The key lesson or turning point
Post N: Close with ONE CTA only (follow, reply, save)
```

## Hook Formulas (proven for X)

- "X errores que cometí al [hacer Y]"
- "Nadie te dice esto sobre [tema]"
- "Hice [acción difícil]. Aquí lo que aprendí:"
- "El dato que cambió cómo pienso sobre [tema]:"
- "[Número] meses después de [proceso], esto es lo que ha pasado realmente"

## Quality Checklist

- [ ] Opener is reshareable on its own
- [ ] Momentum flows — no filler posts
- [ ] Each post < 280 characters (or intentionally uses long-form)
- [ ] Close has exactly ONE ask
- [ ] No links in post 1 (put in reply or final post)

## When NOT to Write a Thread

If the idea fits in 1-2 posts — don't pad it. A single strong post often outperforms a weak thread.
