# /today

Selecciona y genera el mejor contenido posible para publicar hoy.

Proceso:

1. Revisar:
   - `knowledge/`
   - `content/published/`
   - `contenido/tweets-publicados.md`
   - `knowledge/SEPTIEMBRE_2026_AUTOPROMOTORN.md` (READY/SCHEDULED = ya utilizado, no repetir)
   - `content/ideas/`
   - `content/ready/`
   - `content/scheduled/`
   - `content/drafts/`
   - `inbox/notes/`
2. Evitar repetición.
3. Priorizar una experiencia reciente si existe.
4. Seleccionar máximo 3 candidatos.
5. Para cada candidato calcular:
   - personalización;
   - originalidad;
   - fuerza del hook;
   - experiencia real;
   - tensión;
   - potencial de conversación.
6. Elegir el mejor.
7. Generar internamente versiones A/B/C.
8. Guardar solo la mejor.
9. Asignar AUTO o REVIEW.
10. Guardar en `content/ready/`.

Mostrar:
- texto final;
- pilar;
- marco;
- motivo de selección;
- modo AUTO/REVIEW;
- nota visual.
