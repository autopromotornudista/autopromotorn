# /diary

Registra `$ARGUMENTS` como experiencia real de @AutopromotorN.

⚠️ REGLA DE PRIVACIDAD:
Ninguna información registrada con /diary puede usarse para generar contenido público sin autorización explícita.
Los datos de obra, costes, personas o ubicaciones exactas son PRIVADOS por defecto hasta que el protagonista los apruebe.

Proceso:

0. Clasificar la información recibida:

   Si la clasificación no es explícita, preguntar:
   ```
   ¿Cómo clasifico esta información?
   PRIVATE  → solo para knowledge/, nunca para contenido (nombres, ubicaciones, importes no aprobados)
   APPROVED → puede usarse como fuente editorial interna (va a knowledge/ con aprobación)
   PUBLIC   → ya se ha publicado o se aprueba publicar (puede ir a content/)
   ```
   No asumir PUBLIC ni APPROVED. Ante la duda, marcar como PRIVATE.

1. Guardar la experiencia en `inbox/notes/` con fecha y clasificación.
2. Extraer:
   - hecho;
   - decisión;
   - cifras;
   - dudas;
   - resultado;
   - contexto familiar si existe;
   - posibles pilares;
   - posibles marcos mentales.
3. No inventar detalles.
4. Crear 1-5 ideas potenciales en `content/ideas/` si tiene valor editorial.
5. No generar tweet final salvo que se pida.

Formato de cada idea:

ID:
Fecha:
Pilar:
Marco:
Experiencia:
Tensión:
Idea:
Necesita investigación:
Estado: IDEA
